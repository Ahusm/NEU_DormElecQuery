### 宿舍电费信息查询接口

**接口描述**  
根据房间号查询指定宿舍的剩余电量及电表相关信息。

**基本信息**  
- **请求 URL**: `https://pay.neu.edu.cn/queryRommInfo` *(注：URL中 Romm 为原站拼写)*
- **请求方法**: `POST`
- **Content-Type**: `application/x-www-form-urlencoded; charset=UTF-8`

---

#### 1. 请求参数 (Form Data)

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| `elecroomno` | String | 是 | 宿舍房间号 | `1120294` |
| `factorycode`| String | 是 | 厂商/校区代码（通常固定） | `E039` |

#### 2. 关键请求头 (Headers)
> 必须携带以下请求头以确保请求被正常受理（防跨站及会话校验）：
- `Cookie`: `JSESSIONID=<有效的会话ID>`
- `X-Requested-With`: `XMLHttpRequest`
- `Referer`: `https://pay.neu.edu.cn/openPayElecPagesDbdx51414E039.html`
- `Origin`: `https://pay.neu.edu.cn`

---

#### 3. 响应参数 (JSON)

| 参数名 | 类型 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- |
| `returncode` | String | 业务状态码，`SUCCESS` 表示成功 | `"SUCCESS"` |
| `returnmsg` | String | 状态描述信息 | `"ok"` |
| `elecroominfo`| String | 房间完整描述信息 | `"南湖校区学生第十宿舍B区0294寝室"` |
| `elecRemain` | String | 剩余电量（包含单位） | `"159 度"` |
| `mAddr` | String | 电表硬件地址/编号 | `"112012038104"` |
| `lastReadTime`| String | 最后一次抄表/读数时间 | `"2026/9/1 0:00:00"` |
| `facFlag` | String | 厂商服务标识或内网接口地址 | `"http://10.181.200.51:8000/apiv1"` |

*(注：服务端响应的 `Content-Type` 实际为 `text/plain;charset=UTF-8`，但内容为标准 JSON 字符串，解析时按 JSON 处理即可。)*

---

#### 4. 响应示例

```json
{
  "returncode": "SUCCESS",
  "returnmsg": "ok",
  "elecroominfo": "南湖校区学生第十宿舍B区0294寝室",
  "elecRemain": "159 度",
  "mAddr": "112012038104",
  "lastReadTime": "2026/9/1 0:00:00",
  "facFlag": "http://10.181.200.51:8000/apiv1"
}
```

#### 5. 注意事项
1. **会话依赖**：请求依赖有效的 `JSESSIONID`，若 Cookie 失效会返回未授权或重定向。
2. **跨域限制**：接口配置了 `strict-origin-when-cross-origin`，建议在同源环境下或通过后端代理转发调用。
3. **参数固定值**：`factorycode=E039` 对应原页面 `openPayElecPagesDbdx51414E039.html`，若切换校区/宿舍区可能需调整此值。
